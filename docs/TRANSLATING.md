# Translating the interface

The source language of the interface is Czech: the Czech text is also the lookup key.
A language is one JSON file – no build step, no tooling required.

```json
{
  "language": "Deutsch",
  "code": "de",
  "locale": "de-DE",
  "strings": {
    "Uložit": "Speichern",
    "Smazat {0}?": "{0} löschen?"
  }
}
```

- `language` – the name shown in the language selector (top right of the interface)
- `code` – language code, also the file name (`de.json`)
- `locale` – used for dates and number formatting
- `strings` – Czech source text → translation

## Add or adjust a language on your own controller

1. Copy `src/mtcontroller/i18n/template.json` (all source texts, empty translations)
   or `en.json` (English, handy if you do not read Czech) to `<code>.json`.
2. Translate the values. Leave a value empty to fall back to Czech for that text.
3. Put the file into `/var/lib/mtcontroller/i18n/` on the controller
   (create the directory; readable by the `mtcontroller` user).
4. Reload the page – the language appears in the selector. No restart is needed.

Files in `/var/lib/mtcontroller/i18n/` take precedence over the shipped ones, text by
text. So to change a few English wordings, a file with just those entries is enough:

```json
{ "language": "English", "code": "en", "strings": { "Lokalita": "Location" } }
```

The directory survives package upgrades.

## Rules for translations

- **Placeholders** `{0}`, `{1}`, … stand for values (names, numbers). Keep every
  placeholder of the source text; their order may change.
- **Leading and trailing spaces** matter – some texts are joined with others.
  Keep them exactly as in the source.
- `\n` is a line break.
- Short fragments such as `"ů"` or `"y"` are plural endings appended to a word
  (Czech has three plural forms). Translate them to whatever fits, often `"s"`.
- Texts of the setup wizard and messages generated by the server (errors, alerts,
  e-mail notifications) are not translatable yet.

## Contribute a translation

Add `src/mtcontroller/i18n/<code>.json` and open a pull request. Check it first:

```sh
python3 tools/i18n.py check <code>   # missing texts, placeholder mismatches
python3 tools/i18n.py sync <code>    # add new source texts (empty), drop removed ones
```

## For developers

Interface texts in JavaScript go through `__()`:

```js
el("button", __("Uložit"));                    // plain text
msg(__`Smazat ${name}?`);                      // values → key "Smazat {0}?"
```

Static HTML (`index.html`) needs nothing: every text node and the attributes `title`,
`placeholder`, `aria-label` and `alt` are translated when the page loads.

After adding texts run `python3 tools/i18n.py template` and `sync en`, then translate the
new English entries – the test suite fails while `en.json` is incomplete.
